# Maison Monsart

Site vitrine premium — React, Vite, Tailwind CSS.

## Lancer en local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:5173](http://localhost:5173).

## Build pour production

```bash
npm run build
```

Les fichiers statiques sont générés dans `dist/`, prêts à être déployés (Vercel, Netlify, hébergement statique).

## Stack

- **React 18** + **Vite**
- **Tailwind CSS** (couleur dominante `#00082D`, polices Playfair Display + Inter)
- Aucune dépendance lourde supplémentaire
- SEO : balises meta et Open Graph dans `index.html`
